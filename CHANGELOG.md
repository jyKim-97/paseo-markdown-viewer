# Changelog

## 0.1.0 (2026-09-15)

Initial release.

- Read-only markdown workspace panel with tabs, available in the workspace and the Explorer.
- Live updates from a daemon-side file watcher, including atomic saves.
- Follow mode: files an agent writes or edits open as background tabs with an unread dot.
- Unread, active and idle status dots on tabs, styled like Paseo's agent list.
- `/md <path>` slash command, Command Center item, and `bin/open-markdown` for agents.
- Show in Finder.
